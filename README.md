This is an extra light Labwc based build. 
Consumes about ~ 500 MB @ idle.
No Display Mgr. (TTY1 set to auto launch LabWC - IE: "exec dbus-run-session -- labwc" in .bash_profile) 
NO PIPE MENU (completely disabled)
No frills Waybar - TIME, ext/workspaces, wlr/taskbar, BATT.
I tested this on Arch, Fedora, Debian, openSUSE, and Void Linux in an attempt to create a modular setup that can change bases seamlessly.
Install foot, waybar, fuzzel, swaybg, labWC, wlsunset, wlogout and you are up and running EXTREMELY LIGHT AND EFFICIENT!
